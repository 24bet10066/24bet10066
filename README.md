- 🔧 Building **Wrenchy**, a service and spare-parts operations platform inspired by a real family-business use case.

## 🤖 Machine Learning & MLOps Foundations

I'm learning how to take ML work beyond model training and understand the broader lifecycle. My current learning areas include:

- Data preparation, model training, and model evaluation
- Comparing models with appropriate metrics
- Reproducibility, deployment, and monitoring concepts
- Exploring demand forecasting as a **possible future extension** of Wrenchy

I want to apply ML or AI where it can solve a measurable business problem, supported by clear evaluation and reliable software.

## 🧠 How I Approach Engineering

**Understand the problem → Model the workflow → Design the data and APIs → Build and test → Deploy → Measure and improve**

I care about whether the system is understandable, dependable, and useful to the people relying on it, not just whether the code runs.
